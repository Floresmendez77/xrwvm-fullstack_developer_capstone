# Best Cars - Full Stack Dealership Application

**Repositorio:** xrwvm-fullstack_developer_capstone
**Proyecto:** Best Cars

Aplicación web full stack para consultar concesionarios de autos, leer reseñas y publicar nuevas reseñas con análisis de sentimiento. Proyecto final del certificado Full Stack Application Developer de IBM (Coursera).

## Tecnologías

- **Backend:** Django (Python), con autenticación de usuarios (registro, login y logout)
- **Frontend:** React
- **Microservicios:** servicio de concesionarios y reseñas (Node.js/Express con MongoDB) y servicio de análisis de sentimiento (IBM Watson NLU)
- **Despliegue:** Docker, GitHub Actions y Kubernetes en IBM Cloud

## Funcionalidades

- Registro, inicio y cierre de sesión
- Lista de concesionarios, con filtro por estado
- Detalle de cada concesionario con sus reseñas y su sentimiento
- Publicación de reseñas (usuarios autenticados)
- Páginas "About Us" y "Contact Us"
